「吃什么」隐私政策

应用名称：吃什么（热量管家） · 版本 1.0.0
开发者：scr498 · 更新日期：2026年9月26日 · 政策版本：V1.0

引言

「吃什么」是一款完全在您的设备本地运行的饮食与运动记录工具。本应用不连接任何服务器、不上传任何数据、不包含广告与第三方统计组件，您的所有健康数据仅保存在您自己的手机上。

我们深知个人信息对您的重要性，将以高度审慎的态度对待您的信息。本政策将向您说明本应用如何处理（收集、存储、使用、导出与删除）您的信息，以保障您的知情权与选择权。

请您在使用本应用前，仔细阅读并充分理解本政策的全部内容。一旦您开始使用本应用，即表示您已同意本政策的约定。

一、我们记录的信息

本应用为纯本地记录工具，以下信息仅保存在您的设备本地数据库中，用于向您提供热量统计、趋势分析、目标管理等功能：

信息类别具体内容用途
个人基本资料 昵称、性别、生日、身高、体重、所在地区 计算基础代谢（BMI）、推荐每日热量目标
饮食记录 您手动添加的食物名称、分量、热量、用餐时间 每日摄入热量统计与分析
运动记录 您手动添加的运动项目、时长、消耗热量 每日消耗热量统计与分析
身体数据 各时间点的体重、体围等测量记录 体重趋势图表展示
目标与偏好 目标模式（减重/维持/增肌/增重）、活动水平、主题设置 个性化目标计算与界面展示
提醒设置 提醒类型、提醒时间、重复日 在您设定的时间发出饮食/运动提醒
成就数据 由上述记录自动生成的达成状态 成就页面展示

本应用没有账号系统，不收集手机号、设备标识符、位置信息、通讯录、照片等与记录功能无关的信息，也不进行任何用户行为分析或数据统计上报。

二、权限使用说明

本应用仅在实现功能所必需的范围内申请系统权限。您可以在系统设置中随时关闭这些权限，但可能导致对应功能无法使用，不影响其他功能：

权限申请时机用途拒绝后的影响
读取日历 / 写入日历 您开启提醒功能时 将您设置的饮食、运动、喝水等提醒写入系统日历，由系统按时提醒 无法通过日历发出提醒，其余功能不受影响
文件读取 / 写入（备份导出） 您主动使用"备份导出"或"恢复"功能时 将您的自定义数据导出为 JSON 备份文件保存到您选择的位置，或从您选择的文件恢复 无法使用备份与恢复功能

三、信息的存储与安全

1. 存储位置

您的全部数据存储在设备本地的应用数据库中，处于系统的应用沙箱保护之下，其他应用无法直接访问。

2. 不联网

本应用未申请网络权限，不具备将数据发送到任何服务器的能力。除您主动导出的备份文件外，数据不会离开您的设备。

3. 安全措施

我们通过系统提供的应用沙箱隔离机制保护您的本地数据。请您妥善保管设备，并为您导出的备份文件选择安全的存储位置。

4. 存储期限

数据将一直保存在您的设备上，直至您在应用内清除数据或卸载本应用。卸载应用后，本地数据将随应用一并删除，且无法恢复。

四、信息的使用

您在应用内记录的信息仅用于：

  • 每日摄入与消耗热量的统计、图表展示及趋势分析；
  • 根据您的身体数据与目标，计算并推荐每日热量目标；
  • 根据您的记录推荐适合的食物搭配建议；
  • 在您设定的时间通过系统日历发出提醒；
  • 生成成就记录，展示您的坚持与进步。

本应用不会将您的信息用于个性化广告、用户画像、数据出售或任何与上述功能无关的目的。

五、信息的导出与删除

1. 备份导出

您可以在"个人中心 → 数据管理"中使用备份功能，将您的自定义数据（个人资料、饮食与运动记录、身体数据、目标、成就、提醒设置）导出为 JSON 文件，由您自行选择保存位置并妥善保管。

2. 数据恢复

您可以使用恢复功能，从之前导出的 JSON 备份文件中恢复数据。

3. 清除数据

您可以在"个人中心 → 数据管理"中按类别（饮食记录、运动记录、身体数据、目标、成就、每日数据、个人资料）清除对应数据，该操作不可撤销。

4. 卸载删除

卸载本应用将删除应用内的全部本地数据。如需保留数据，请先使用备份导出功能。

六、第三方服务

本应用不集成任何第三方广告、统计、推送、地图或社交组件，不与任何第三方共享您的信息。

七、未成年人保护

本应用记录的健康数据属于敏感个人信息。我们建议未成年人在监护人的指导下使用本应用，并由监护人协助设置合理的热量目标。若您是未成年人的监护人，认为本应用记录了不当信息，您可以通过应用内的清除数据功能随时删除。

八、政策的更新

当应用功能发生可能影响您个人信息的变化时，我们将更新本政策。重大变更将通过应用内公告或"关于"页面提示等方式通知您。建议您定期查阅本政策的最新版本。
